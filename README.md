# Weatherly - Simple Weather App

A clean and easy-to-use weather application built with HTML, CSS, and JavaScript.

## What it does
- Shows current weather for any city
- Displays 5-day weather forecast
- Works on mobile and desktop
- Uses your current location
- Quick search for popular cities

## Features
- Real-time weather data
- Beautiful purple theme
- Responsive design
- Easy to use interface
- Fast and lightweight

## How to use
1. Download all files
2. Get a free API key from WeatherAPI.com
3. Put your API key in the script.js file
4. Open index.html in your browser
5. Search for any city and get weather updates!

## Files included
- `index.html` - Main page
- `styles.css` - All styling
- `script.js` - Weather functionality

## Built with
- HTML5
- CSS3
- JavaScript
- WeatherAPI.com
- Font Awesome icons
- Google Fonts

## Setup
1. Sign up at https://www.weatherapi.com
2. Copy your free API key
3. Replace `YOUR_API_KEY_HERE` in script.js with your key
4. Save and open index.html

That's it! Your weather app is ready to use.
